# Pokémon: Chat Edition

Deze applicatie is gemaakt in react met als backend een LLM met een server op Express. Hierbij heb ik mijn eigen bot
gemaakt door de prompt engineering.

## Done:

### Begrip van Techniek

- Prompt vanuit node (10 punten)
- Frontend kan prompt sturen + chat bubbles (30 punten)
- Submit button is inactief & Markdown word correct getoond (40 punten)
- Streaming (50 punten)

### Begrip van Taalmoddelen

- Opdrachten ingeleverd (10 punten)
- User interface, System prompt met tone of voice en gedrag past bij useCase (30 punten)
- Node server houd tokens & history bij (40 punten)
- Taalmodel geeft JSON structured output (50 punten)
